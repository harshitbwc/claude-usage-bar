Up and running in a minute

Three steps, and you'll never wonder how much Claude you have left.

  1. Download the appGrab ClaudeUsageBar.dmg, open it, and drag the app into Applications.
  2. Open it the first timeThe app isn't notarized yet, so macOS asks for a nudge: right-click it in Applications, choose Open, then Open again.
  3. Look upYour usage bar appears in the menu bar. If macOS asks about the Keychain, choose Always Allow.

You'll need Claude Code installed and logged in on the same Mac. That's where the app reads your login.

Questions

Is this official?

No. Claude Usage Bar is an independent project and isn't affiliated with or endorsed by Anthropic. It relies on an undocumented usage endpoint, so it could stop working if that changes.

Is it safe? What does it do with my login?

It reads the login Claude Code already stores in your Mac's Keychain and sends it only to Anthropic's own API to fetch your usage. No analytics and no other servers. If your login has expired, it refreshes it the same way Claude Code does. You can read every line in the source code.

Why do I need Claude Code?

The app borrows Claude Code's saved login instead of asking for your password. Without Claude Code, there's no login to read and the app shows "No Claude login found".

Do the numbers match Claude's own usage page?

Yes. They come from the same data as Settings → Usage on claude.ai and the /usage command in Claude Code, not from an estimate.

Does it work on Intel Macs?

Yes. The download is a universal app that runs on both Apple Silicon and Intel, on macOS 13 or later.
